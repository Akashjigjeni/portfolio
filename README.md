# 🌐 Akash Jigjeni — Personal Portfolio

Welcome to my personal portfolio website.

This project is a digital portfolio designed to showcase my profile, technical skills, certifications, and learning journey in AI, Data Science, Generative AI, Data Analytics, and Cybersecurity.

## 👨‍💻 About the Project

This portfolio represents my technical learning and professional development. It presents my skills and credentials in a clean, interactive, and responsive web interface.

The portfolio is designed as a "Credential Ledger" rather than a traditional resume.

## ✨ Features

- 👤 Personal profile and introduction
- 💻 Technical skills section
- 🏆 Certificates and credentials
- 🔗 Certificate verification links
- 🌙 Light and dark mode
- ⚙️ Profile settings
- ➕ Add new certificates
- 📱 Responsive design
- 📧 Contact information
- 🔗 Social media links

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts
- Browser Local Storage
