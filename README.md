# Akash Jigjeni — Credential Ledger & Engineering Portfolio

An editorial, credential-first developer portfolio and verified certificate ledger designed for **Akash Jigjeni**, Aspiring AI & Data Systems Engineer at Nutan Maharashtra Institute of Engineering and Technology (NMIET), Pune.

---

## 🌟 Key Features

- **📜 Verified Credential Ledger**: Showcases real credentials across IBM Cognitive Class, Cisco Networking Academy, GeeksforGeeks, Adobe Learning Manager, and Moodle.
- **🔍 Instant Verification & Preview**: Direct online verification links (`Verify ↗`) and a full lightbox certificate inspector.
- **📥 Dynamic Certificate Downloads**: Download high-resolution certificate images or dynamically generate official verified PNG certificates via HTML5 Canvas (`Download ↓`).
- **📬 Direct Contact Channels**: One-click actions for **Email** (`mailto:`), **Direct Call** (`tel:`), and **WhatsApp** (`https://wa.me/`).
- **🌓 Dual Theme Engine**: Bespoke Light ("warm paper ledger") and Dark ("deep forest slate") modes with local persistence.
- **⚙️ Profile Customizer**: Live browser-backed settings modal to update bio, education status, contact information, and social links.
- **➕ Client-Side Certificate Uploader**: Easily add new certificates with instant preview and local storage caching.

## 🚀 How to Run Locally

1. **Clone the repository**:
   ```bash
   git clone https://github.com/<your-username>/<your-repo-name>.git
   cd <your-repo-name>
   ```

2. **Open in browser**:
   - Simply double click `index.html` or open it with any browser (Chrome, Edge, Firefox, Safari).
   - Alternatively, serve with VS Code **Live Server** or `npx serve .`.

---

## 🌐 Deploying to GitHub Pages

1. Push this repository to your GitHub account.
2. Go to **Settings** > **Pages** in your repository.
3. Under **Branch**, select `main` (or `master`) and the `/ (root)` folder.
4. Click **Save**. Your portfolio will be live at `https://<your-username>.github.io/<your-repo-name>/`.
